# Documentação do Projeto ATTALUS

Este diretório contém toda a documentação oficial referente ao Projeto ATTALUS, incluindo infraestrutura, redes, arquitetura, padrões internos e diretrizes operacionais.

## Estrutura

- **jornada/** — Documentação numerada (00 a 07) que registra a evolução cronológica do projeto: planejamento, topologia, configurações, segurança, monitoramento, políticas e roadmap.
- **referencia/** — Documentação técnica viva, organizada por domínio, atualizada conforme o ambiente muda:
  - **infra/** — Guias técnicos e informações sobre servidores, virtualização e sistemas.
  - **rede/** — Documentação relacionada à rede e seus serviços.
  - **seguranca/** — Políticas e diretrizes de segurança, controles e hardening.
  - **operacoes/** — Procedimentos de operação, suporte e resposta a incidentes.

A documentação será expandida conforme o projeto evolui.
